# Macropolitan アプリアイコン — 制作経緯と権利情報

本書は、新しいMacropolitanアプリアイコンの制作経緯と確認状況の記録です。Micropolis由来のゲーム画像・音声の出典情報とは区別します。

## 制作経緯

開発者から、次の制作方法が報告されています。

1. OpenAIのChatGPTによる画像生成を使用。
2. 生成された画像をもとにアイコンを制作。
3. Apple Icon Composerで仕上げ。
4. Macropolitanのアプリアイコンとして採用。

これは制作に使用したツールの説明です。OpenAI、ChatGPTまたはAppleがMacropolitanを公式に後援・承認・推奨していることを示すものではありません。

## 対象ファイル

対象は `apps/micropolis-macos/Macropolitan_Icon.icon/` 内のアプリアイコン一式で、以下の構成・画像ファイルを含みます。

- [icon.json](Macropolitan_Icon.icon/icon.json)：Icon Composerの構成。
- [Assets/Image 3.png](Macropolitan_Icon.icon/Assets/Image%203.png)：アイコンの画像。

旧Canvaアイコンは移行対象から除外済みで、本書の対象ではありません。
